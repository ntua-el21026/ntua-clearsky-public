# AI-assisted coursework record

This directory retains Team 15’s questionnaire archives from the NTUA
Software as a Service course. Where provided, session metadata identifies
the activity and the associated dialogue records prompts and outputs. The
archives document the team’s development process alongside the separate
implementation and model.

The [NTUA AI log tool](https://ailog.softlab.ntua.gr/) and its CLI provided
the original submission channels. The archives are historical evidence.
They are independent of running the [application](../README.md).
